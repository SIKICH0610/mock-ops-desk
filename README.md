# Mock 考务台 · Mock Exam Ops Desk

Think Academy mock-exam operations tool — runs entirely in the browser, no data leaves your device.

- **考前**：拖入报名表 → 自动分场分座 → 打印座位贴 / 签到表 / 下载考场安排
- **考后**：拖入扫卡结果 → 自动判分（AMC 规则）→ 成绩总表 / 查分小纸条一键复制进邮件
- 表头按含义自动识别，改名不影响；题数由标准答案长度决定，可套用不同考试

Open: the GitHub Pages URL of this repo (`index.html` is the whole app, single file).
